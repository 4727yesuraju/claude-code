# Channels

## 📖 Simple English Explanation

**Channels** are the different ways Claude Code can communicate with you or work with your development environment.

Claude Code can be used through different interfaces, such as the **terminal, code editor, or desktop application**.

Each channel gives you a different way to interact with Claude Code.

---

## 🤔 Why is it Needed?

Different developers prefer different workflows.

For example:

* **Terminal** → Good for command-line workflows
* **Code Editor** → Good when coding and reviewing changes
* **Desktop** → Good for a visual workflow

The important thing is that **Claude Code can work with your project through these different channels**.

---

## 🌊 Simple Flow

```text
                 Claude Code
                     ↓
        ┌────────────┼────────────┐
        ↓            ↓            ↓
     Terminal    Code Editor    Desktop
        ↓            ↓            ↓
              Your Project
```

---

## 💻 Example

You are working on a React project.

### Terminal

```text
claude
```

Ask:

```text
Find the authentication code.
```

### Code Editor

Open your project in the editor and interact with Claude Code while viewing your code.

### Desktop

Open Claude Code Desktop and work with your project through the graphical interface.
