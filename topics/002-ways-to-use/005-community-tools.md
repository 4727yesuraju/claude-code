# Community Tools

## 📖 Simple English Explanation

**Community Tools** are tools created by developers and the Claude Code community.

They are **not necessarily built or maintained by Anthropic**.

These tools can add extra features or make Claude Code easier to use.

---

## 🤔 Why is it Needed?

Claude Code already provides many features, but community developers may build tools for specific needs.

For example, community tools can help with:

* Custom workflows
* Automation
* Integrations
* Productivity
* Project management
* Additional development features

---

## 🌊 How It Works

```text
Claude Code
     ↓
Community Developers
     ↓
Build Extra Tools
     ↓
You Install / Use Them
     ↓
Extended Workflow
```

---

## 💻 Example

Imagine a developer creates a tool that helps Claude Code follow a specific development workflow.

Instead of manually doing:

```text
Read requirements
      ↓
Create files
      ↓
Write tests
      ↓
Run tests
      ↓
Fix errors
```

A community tool might help automate part of this workflow.

---

## ⚠️ Important

Community tools are **third-party tools**.

Before using one, check:

* Who created it?
* Is it actively maintained?
* What permissions does it need?
* Is the source code trustworthy?
* What data does it access?
