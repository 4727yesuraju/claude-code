# Claude Code Models

## 📖 Simple English Explanation

**Models** are the AI models that Claude Code uses to understand your requests and work with your code.

Different models can have different levels of **speed, intelligence, and cost**.

You can choose a model depending on the type of task you are doing.

---

## 🤔 Why is it Needed?

Not every task needs the most powerful model.

For example:

* Simple question → a faster model may be enough.
* Complex coding task → a more capable model may be better.
* Large reasoning task → you may want a stronger model.

Choosing the right model can help you balance **quality, speed, and usage**.

---

## 🌊 Simple Flow

```text
Your Task
    ↓
Choose a Claude Model
    ↓
Claude understands the task
    ↓
Generates / changes code
    ↓
You review the result
```

---

## 💻 Example

Suppose you ask:

```text
Explain what this function does.
```

A faster model may handle this easily.

But if you ask:

```text
Understand this large codebase,
find the performance problem,
design a better solution,
implement it,
and test it.
```

A more capable model may be a better choice.

---

## 🔑 Important Idea

Think of Claude models like **different tools for different jobs**.

```text
Simple Task
    ↓
Faster / lighter model

Complex Task
    ↓
More capable model
```

The available model names and model-selection behavior can change over time, so the exact models shown in Claude Code depend on the current version and your account.

---

## 🎯 Simple Understanding

> **Claude Code Models = The different AI models you can use to perform tasks in Claude Code.**

The main things to consider are:

**Capability + Speed + Cost**
