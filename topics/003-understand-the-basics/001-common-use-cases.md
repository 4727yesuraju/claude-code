# Common Use Cases

## 📖 Simple English Explanation

**Use cases** are the common things you can use **Claude Code** for.

Claude Code is not only for writing code. It can help with many parts of software development, from understanding an existing project to testing and debugging it.

---

## 🤔 Why is it Needed?

Knowing the common use cases helps you understand **when Claude Code is useful**.

Instead of asking only:

> "Write code for me."

You can use Claude Code as a coding assistant for different development tasks.

---

## 💻 Common Use Cases

### 1. 🔍 Understand Code

Ask Claude to explain existing code.

```text
Explain how the authentication flow works in this project.
```

---

### 2. ✨ Write New Code

Ask Claude to create a new feature.

```text
Create an API endpoint to get all customers.
```

---

### 3. 🐛 Debug Code

Give Claude an error and ask it to find the cause.

```text
This API is returning a 500 error. Find the problem.
```

---

### 4. 🔄 Refactor Code

Ask Claude to improve existing code without changing its behavior.

```text
Refactor this function to make it easier to read.
```

---

### 5. 🧪 Write Tests

Claude can create tests for your code.

```text
Write unit tests for the CustomerService.
```

---

### 6. 📚 Understand a New Project

Claude can explore a project and explain its structure.

```text
Explain the architecture of this project.
```

---

### 7. 🔎 Find Code

You can ask Claude to locate where something is implemented.

```text
Where is the customer creation logic?
```

---

### 8. 📝 Documentation

Claude can help create or update documentation.

```text
Update the README with the new API setup instructions.
```

---

### 9. 🔧 Git Work

Claude can help with Git-related tasks.

For example:

```text
Review my current changes and summarize them.
```

---

### 10. 🚀 Development Workflow

Claude can help you perform multiple steps together:

```text
Add the new customer API,
write tests for it,
run the tests,
and fix any failures.
```

---

## 🌊 Simple Flow

```text
Understand
    ↓
Plan
    ↓
Code
    ↓
Test
    ↓
Debug
    ↓
Refactor
    ↓
Document
```

Claude Code can assist throughout this workflow.

---

## 🎯 Simple Understanding

> **Claude Code can help with the complete software development workflow — not just writing code.**

Think:

```text
Understand → Build → Test → Debug → Improve
```
