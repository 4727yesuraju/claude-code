# MCP

## 📖 Simple English Explanation

**MCP (Model Context Protocol)** is a standard way for Claude Code to connect to **external tools and services**.

Claude Code can already work with your local project. MCP allows it to connect to additional systems such as databases, APIs, documentation, or other services.

Think of MCP as a **bridge between Claude Code and external tools**.

---

## 🤔 Why is it Needed?

Claude Code may need information or actions that are outside your local project.

For example, you may want Claude to:

* Query a database
* Access an external API
* Search company documentation
* Work with GitHub
* Interact with another service

MCP makes these connections possible in a standard way.

---

## 🌊 How It Works

```text
You
 ↓
Claude Code
 ↓
MCP
 ↓
External Tool / Service
 ↓
Result
 ↓
Claude Code
 ↓
You
```

---

## 💻 Example

Imagine you have an MCP server connected to your database.

You ask Claude:

```text
Show me the customers created today.
```

The flow can be:

```text
Claude Code
    ↓
MCP
    ↓
Database
    ↓
Customer data
    ↓
Claude Code
    ↓
Shows the result
```

Claude doesn't need to manually know how your database connection works. The MCP server provides the tools Claude can use.

---

## 🔑 MCP Server

An **MCP server** is a program that exposes tools or information to Claude Code.

For example:

```text
Claude Code
     ↓
MCP Server
     ↓
┌───────────────┐
│ Database      │
│ GitHub        │
│ API           │
│ Documentation │
└───────────────┘
```

Different MCP servers can provide different capabilities.
