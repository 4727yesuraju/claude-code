# 💳 Subscription Options & API Usage

## 📖 Simple English Explanation

Claude can be used in two main ways:

1. **Claude subscription** — use Claude through Claude's apps/web interface and supported Claude Code access.
2. **API usage** — use Claude from your own applications by sending requests to the Anthropic API.

For Claude Code, your available access depends on the account/subscription or API setup you use.

---

## 🤔 Why is it Needed?

Understanding the difference helps you choose the right option.

* If you want to **use Claude personally for coding**, a subscription can be convenient.
* If you want to **build an application that calls Claude**, you normally use the API.
* API usage is generally charged based on how much you use the model.

---

## 🔄 Subscription vs API

| Subscription                          | API                           |
| ------------------------------------- | ----------------------------- |
| For using Claude as a user            | For applications/developers   |
| Usually a recurring plan              | Pay based on API usage        |
| Use Claude through supported products | Send requests from your code  |
| Good for personal coding work         | Good for building AI features |

---

## 💻 Example

### Using Claude Code

You can use Claude Code to work on your project:

```text
You → Claude Code → Your Project
```

You might ask:

```text
Find the authentication code and explain how it works.
```

Claude Code works with your project and helps you modify or understand the code.

### Using the API

An application can send a request to Claude:

```text
Your Application
       ↓
Anthropic API
       ↓
Claude Model
       ↓
Response
       ↓
Your Application
```

For example, a Node.js application could use the API to generate a response for a user.

---

## 🎯 Important Difference

**Claude subscription ≠ API credits**

Having a Claude subscription does not automatically mean your application can freely use the Anthropic API.

Think of them as **two different ways of accessing Claude**:

```text
Claude Subscription → You use Claude
API                 → Your application uses Claude
```
