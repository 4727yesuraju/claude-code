# Coding Agent

## 1. 📖 Simple English Explanation

A **Coding Agent** is an AI that can **understand a coding task, plan the work, write code, use tools, test the code, and fix problems**.

Unlike a normal chatbot, a coding agent can work with your project files and take multiple steps to complete a task.

## 2. 🤔 Why is it Needed?

* 🚀 Build features faster
* 🐛 Find and fix bugs
* 🧪 Run tests and check the code
* 📂 Understand and modify multiple files
* 🔄 Handle multi-step coding tasks
* 💡 Reduce repetitive development work

## 3. 🌊 Flow

```text
You give a coding task
        ↓
Agent understands the project
        ↓
Agent creates a plan
        ↓
Agent writes/changes code
        ↓
Agent runs tests/tools
        ↓
Found a problem?
        ↓
Agent fixes it
        ↓
Final working code
```

## 5. 💻 Example

You ask:

> "Add JWT authentication to my MERN application."

A coding agent can:

1. Inspect the existing project
2. Understand the backend structure
3. Create authentication logic
4. Update routes and middleware
5. Update the database model
6. Run tests
7. Fix errors
8. Explain the changes

## 6. 🧠 Memory Trick

**Coding Agent = Understand → Plan → Code → Test → Fix**

> **Chatbot gives you code. Coding Agent can work on the codebase.**
